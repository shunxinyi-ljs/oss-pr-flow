# 闸门四输出模板

固定四段，顺序不变。语言跟随原 issue/PR 的语言。

```
## 终稿
<可直接粘贴的正文，不含批注、方括号占位、审查说明>

## 待确认清单
- [必须补] ... —— 缺什么证据，影响哪句表述
- [建议补] ...
（没有则写"无"）

## 改动摘要
- 删除 / 重排 / 措辞降级：原表述 → 新表述，原因
（只列影响事实表达的改动，不列错别字）

## 提交命令（确认前不执行）
<git push 与 gh pr create --draft 命令，标题与正文使用终稿>
```

正文较长时命令用 `--body-file`：经用户同意后把正文写到仓库外的临时文件，用完即删；短正文用内联方式。
